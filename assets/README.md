# assets/

## Обложка

`cover.jpg` — 1024×1024, заголовок обоих README. Созвездие: точки на двух
планах, ближний ярче и смещён относительно дальнего — это и есть параллакс,
от которого имя. Сгенерировано Gemini, выбрано Яриком 03.09.2026.

`social-preview.png` — то же самое в 1280×640 под «Social preview» GitHub
(Settings → General → Social preview). Размер не выдуман: у GitHub картинка
превью обрезается до 2:1, и квадрат он срезал бы сверху и снизу прямо по
рисунку. Поэтому здесь созвездие вписано по высоте, а поля добраны фоном
оригинала (#0f1014) — обрезать диагональную композицию нечем.

Пересобрать превью из обложки, если она поменяется:

```python
from PIL import Image
src = Image.open("cover.jpg").convert("RGB")
W, H, поле = 1280, 640, 40
сторона = H - поле * 2
холст = Image.new("RGB", (W, H), (15, 16, 20))
холст.paste(src.resize((сторона, сторона), Image.LANCZOS),
            ((W - сторона) // 2, (H - сторона) // 2))
холст.save("social-preview.png", optimize=True)
```

## shots/

`desktop.jpg`, `canvas.jpg`, `overview.jpg`, `cube.jpg` — снимки в обоих README,
1600×900, JPEG q90 без прореживания цветности (4:4:4: в кадре мелкий
терминальный шрифт, и обычное 4:2:0 мылит его по краям). Сняты 05.09.2026.

**Чем сняты.** Headless-харнесс (`./harness.sh`, монитор 2560×1440), сборка
`plx-extra`, кадр — `./ctl.py 'shot <путь>'`. То есть не живой сеанс: в кадр не
попадает ни чужая переписка, ни чужие процессы, а сцена собирается одними и
теми же командами, сколько бы раз её ни пересняли. Три стола: fastfetch +
аквариум + кусок `default_config.lua`, cmatrix + часы, pipes + `plx-host --help`.

**Что в конфиге.** Харнесс берёт `default_config.lua` и добавляет поверх то,
ради чего снимок и делается: `blur = true`, `glow = 0.6`,
`sun = 0.9, sun_x = 0.14, sun_y = 0.72` и (для куба)
`cube = 0.8, cube_fill = 0.56, cube_focal = 1.7, cube_shade = 0.5`. По
умолчанию все они выключены — снимок показывает `plx-extra` с включёнными
эффектами, и подписи под кадрами это говорят.

**Обои.** Свои, сгенерированные: снимки уходят в репозиторий под GPL, и чужой
картинке с обойного сайта там не место. Мотив тот же, что у обложки, — ОДНО
созвездие на двух планах, ближний ярче и смещён относительно дальнего (это и
есть параллакс). Цвет один и явный: `glow` и `sun` красятся акцентом палитры,
которую plx-wall считает по обоям, и на такой картинке видно, откуда он взялся.

```python
# Кратко: точки в диагональной полосе, рёбра к ближайшему соседу (длиннее трети
# экрана — не рисуем, иначе созвездие превращается в паутину), и весь рисунок
# кладётся дважды: тусклым со сдвигом (+90,−60) и ярким со сдвигом (−90,+60).
холст = Image.new("RGB", (2560, 1440), (15, 16, 20))
холст = ImageChops.add(холст, план(сдвиг=(90, -60), масштаб=0.92, цвет=(74, 104, 132)))
холст = ImageChops.add(холст, план(сдвиг=(-90, 60), масштаб=1.0, цвет=(104, 176, 232)))
```

## Nunito

`Nunito-Regular.ttf`, `Nunito-SemiBold.ttf` — статические начертания Nunito,
взятые с `fonts.gstatic.com` через CSS API v1 (старый User-Agent заставляет
Google отдать один TTF на начертание целиком, а не порезанный по unicode-range):

```
curl -A "Mozilla/4.0" "https://fonts.googleapis.com/css?family=Nunito:400,600&subset=latin,cyrillic"
```

Лицензия — SIL Open Font License 1.1, полный текст в `Nunito-OFL.txt`. Шрифт
вшивается в бинарь через `include_bytes!` (см. `src/text.rs`), то есть
распространяется вместе с parallax — файл лицензии обязан лежать рядом.

Покрытие проверено по таблице cmap обоих файлов: ASCII 0x20..0x7E целиком,
кириллица 0x400..0x45F целиком, «…» (0x2026), «№» (0x2116), «°» (0x00B0).
Символа питания «⏻» (0x23FB) в шрифте нет — но значки parallax рисует не шрифтом,
а битмап-масками (`text::bitmap_fit`), так что это ничего не задевает.
