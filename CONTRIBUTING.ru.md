# Как участвовать

*[In English](CONTRIBUTING.md)*

Parallax — композитор одного человека, доросший до состояния, в котором его
можно запустить у себя. Правки приветствуются; отчёт об ошибке, где просто
описано, что ты увидел, — тоже. Писать можно по-русски или по-английски.

## Прежде чем начинать

Две вещи в этом дереве удивляют всех, кто открывает его впервые.

**Комментарии и имена — по-русски.** Не строки, которые видно на экране (они
идут через `т!`/`тф!` и существуют на обоих языках), и не логи — те всегда
английские, потому что лог попадает в чужой отчёт об ошибке. А вот
`fn найти_окно`, `struct Холст` и каждый комментарий — да. Это осознанно и
меняться не будет: автор думает по-русски, а композитор — это в основном
рассуждение, а не поверхность API. Патч с английскими именами не отвергнут —
его возьмут и переведут; напиши об этом в PR, и никто не будет гадать.

**Комментарии объясняют «почему», и подробно.** Блок, который дался за день,
несёт с собой рассказ о том, как было неправильно раньше, и часто — замер,
которым это доказано. Пожалуйста, держись той же привычки во всём неочевидном.
«Починил хит-тест» стоит меньше, чем «X зажимает указатель в корневое окно, а
наш холст бесконечен — отсюда и смещение».

## Сборка

Rust через rustup, `pkg-config`, компилятор C и dev-пакеты из шапки
`build_portable.sh`. Lua собирается из исходников самим `mlua`.

```sh
./build.sh                       # оба бинаря, в /mnt/plx-build/target
cargo build --release -p plx-standard
cargo build --release -p plx-extra
```

Никогда не `cargo build --workspace`. Cargo объединяет фичи между членами
workspace, и один такой вызов даёт два бинаря, в каждом из которых лежит всё.
Это замер, а не опасение: после одного `--workspace` оба бинаря весили 17.8 МиБ
байт в байт, и в «стандартном» лежал openxr. `build.sh` зовёт cargo дважды, с
раздельными `--target-dir`, ровно поэтому.

`.cargo/config.toml` в репозитории линкует через `mold` и компилирует с
`target-cpu=native` — верно для машины автора и неверно для твоей, если у тебя
нет mold или не Zen 3. Перебивается переменной `RUSTFLAGS` (она старше файла
настроек) или правится локально; `build_portable.sh` уже делает переносимо.

## Как проверить правку

Не отправляй изменение, которое ты только обдумал. Посмотреть на него есть два
дешёвых способа.

**Headless-харнесс** — полноценный композитор со своим `HOME`, своей шиной
D-Bus и управляющим сокетом, но без экрана и без ввода. Живой сеанс он не
задевает, так что запускать можно прямо во время работы:

```sh
./harness.sh                       # один выход 2560x1080
MODE=1920x1280@60,2560x1080@60 ./harness.sh    # два монитора
./ctl.py 'shot /tmp/a.png'         # снять кадр
./ctl.py windows                   # что открыто и какого размера
./ctl.py 'key logo+space'          # нажать (модификаторы: logo, shift, ctrl, alt)
./ctl.py 'action toggle_overview'  # или выполнить действие по имени, без клавиш
./ctl.py help                      # всё, что он понимает
```

Всё, что считает координаты холста, гоняй на двух мониторах. Дом второго
выхода — (1 000 000, 0), и ошибка «считаем от нуля холста» на одном мониторе
не видна вовсе.

**Тесты** — около двухсот, все чистые: геометрия холста, дерево тайлинга,
разбор конфигурации, кадрирование протоколов. Экран не нужен.

```sh
cargo test --features extra
```

## Грабли, на которые тут уже наступали

Каждая стоила настоящих часов. Примерно по частоте.

- **Кириллическое имя переменной в shell — не переменная.** `имя=значение`
  bash разбирает как КОМАНДУ, падает с «command not found», и `set -e` этого не
  ловит (присваивание внутри `if` — не последняя команда конвейера). Так молча
  перестал выполняться `chown` в `build.sh`, а весь `migrate.sh` не делал
  ничего, выходя с кодом 0. Имена ФУНКЦИЙ кириллицей bash допускает.
  **Имена переменных — только латиницей.**
- **Односимвольные кириллические имена в Rust.** `с`/`c`, `р`/`p`, `о`/`o`,
  `г`/`r` на экране неотличимы, и `confusable_idents` в этом прав. Тем не менее
  линт разрешён на весь крейт в `src/lib.rs` — причина написана над атрибутом:
  он ругается на ОДНУ пару за раз, правка одного места просто всплывает в
  следующем файле, а в русском коде гомоглифы норма, а не опечатка. Это решение
  про ЛИНТ, а не про имена: имя, которое читается (`рад`, `глуб`, `статус`),
  лучше одной буквы, и новых односимвольных кириллических локальных не заводи.
- **Справочник по конфигурации — ДВА файла.** `default_config.lua`
  (английский, он же вшит в бинарь) и `default_config.ru.lua` (русский)
  отличаются только комментариями: ручка, добавленная в один, обязана появиться
  в другом на той же строке. `config::tests::два_справочника_совпадают`
  сравнивает всё, что не комментарий, и падает, если они разъехались.
- **`cargo fmt` по всему дереву** даёт разницу в 28 тысяч строк. Дерево не
  отформатировано rustfmt'ом. Форматируй руками те строки, которые тронул, в
  стиле соседних.
- **`pgrep -f` и `pkill -f` находят сами себя**, а `pkill -f parallax` из
  скрипта с удовольствием убьёт живой сеанс на TTY. Харнесс отстреливает по
  `XDG_RUNTIME_DIR` из `/proc/*/environ` — делай так же.
- **Сплошные цвета обязаны быть premultiplied** перед отправкой в smithay,
  иначе выходят белыми прямоугольниками.
- **Отсутствующий ключ в `config.lua` читается как `false`**, а не как nil —
  так устроен mlua. Из-за этого каждый `set{}` гасил настройки, которых не
  упоминал. Добавляя булев ключ, посмотри в `config.rs`, как существующие
  отличают «нет ключа» от «false».

## Устройство исходников

`src/` нарочно плоский — один файл на подсистему, ~57 000 строк в 81 файле.

| | |
|---|---|
| `lib.rs`, `state.rs` | запуск, цикл событий, общее состояние |
| `canvas.rs`, `anim.rs`, `monitors.rs` | бесконечная плоскость, камера, дуги анимаций |
| `tiling.rs`, `dwindle.rs`, `columns.rs`, `fullscreen.rs` | раскладки |
| `overview.rs`, `switcher.rs`, `constellation.rs` | перемещение по холсту |
| `bar.rs`, `tray.rs`, `sni.rs`, `wifi.rs`, `audio.rs`, `bluetooth.rs` | встроенная оболочка |
| `blur.rs`, `rounded.rs`, `decor.rs`, `icons.rs`, `text.rs` | отрисовка |
| `udev.rs`, `winit.rs`, `headless.rs` | бэкенды: TTY/DRM, вложенный, харнесс |
| `xwayland.rs`, `xwin.rs` | клиенты X11 и починки, нужные играм |
| `input.rs`, `touchpad.rs`, `gestures.rs`, `grabs/` | ввод |
| `config.rs`, `lang.rs`, `ctl.rs` | конфигурация на Lua, переводы, управляющий сокет |
| `vr/`, `mine/`, `share/` | необязательное, у каждого есть двойник `*_stub/` |

Каталог `*_stub/` — тот же модуль той же формы, ничего не делающий. Поэтому в
вызывающем коде нет ни одного `#[cfg]`: выключение фичи подменяет реализацию,
а не удаляет вызов.

## Коммиты

Заголовки в этом репозитории русские и называют сперва область, потом суть:
`Оформление: панель, шрифт, скругление, блюр, значки`. Пиши как удобно; ясный
заголовок важнее языка.

Одно смысловое изменение на коммит. Если нашёл и баг, и его причину — причину в
сообщение коммита: туда посмотрит следующий.

лицензией проекта. Чужое, на чём стоит Parallax, перечислено в
[THIRD-PARTY.md](THIRD-PARTY.md); если твоя правка переносит код откуда-то ещё,
